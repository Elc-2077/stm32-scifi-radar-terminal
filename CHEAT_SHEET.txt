│                                                                   │

│                                                                   │
│     while (1)                                                     │
│     {                                                             │
│         // 你的主循环代码                                         │
│         Delay_Ms(100);                                            │
│     }                                                             │
│ }                                                                 │
└───────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────┐
│ 🐛 常见问题解决                                                   │
├───────────────────────────────────────────────────────────────────┤
│ ❌ multiple definition of main                                    │
│ ✅ 解决: 检查 build_src_filter，只包含一个应用目录               │
│                                                                   │
│ ❌ 找不到头文件                                                   │
│ ✅ 解决: 在 build_flags 添加 -I<目录路径>                        │
│                                                                   │
│ ❌ undefined reference to 'xxx'                                   │
│ ✅ 解决: 在 build_src_filter 添加对应的 .c 文件                  │
│                                                                   │
│ ❌ 上传失败                                                       │
│ ✅ 解决: 检查 ST-Link 连接、驱动安装                             │
│                                                                   │
│ ❌ Flash 空间不够                                                 │
│ ✅ 解决: 移除不必要的图片数据、优化代码                          │
